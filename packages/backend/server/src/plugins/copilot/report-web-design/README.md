# LocalMind 网页汇报设计说明

本包采用固定版本 huashu-design 的题材分析、构图、字体与视觉复核方法，按 LocalMind 一次提交的响应式网页契约改编。来源提交、文件校验值与适配版本见 manifest.json，原许可证见 LICENSE.upstream。

执行规则由 LocalMind 的权限、预算、结构化协议、净化器和受控浏览器决定。三方向探索在规划调用内自动选择，不要求用户选稿；不执行上游脚本、不加载个人偏好文件、不使用固定比例画布、不访问外部素材。

运行通过版本化 DB 提示词解析并固定有效快照，不从宿主机技能目录读取。本包中的原始 hash 用于来源审计；实际运行另记录有效提示词 hash，管理员覆盖不会被种子更新覆盖。

适配版本 1.1.0 使用独立的 `Report Web * v3.1` 提示词，已有 v3 运行继续读取自身冻结快照，不覆盖管理员已有提示词。规划阶段新增 `artDirection`（主视觉、色彩角色、字体尺度、逐章 treatment、图表编码），并校验章节和事实归属。长篇优先用封面与有图表的章节作为样章；后续批次获得已用构图信息。复核阶段收到真实字体测量，分别评价构图、字体、图表；`needs_work` 必须有对应修正 issue，沿用最多两轮的有界修正流程。
