# Contributing to LocalMind

Use the repository setup and validation instructions in [AGENTS.md](../AGENTS.md)
and [BUILDING.md](./BUILDING.md). Open issues and pull requests against
`Infinimesh-ai/LocalMind`.

Keep changes scoped, preserve upstream-compatible package and protocol names,
and include focused tests for behavioral changes. Do not commit credentials,
private document content, or generated artifacts that are not maintained by the
repository's existing generation commands.
