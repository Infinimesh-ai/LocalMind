# LocalMind 使用提示

这份简明提示可直接提供给普通用户。完整说明见
[LocalMind 用户使用指南](./localmind-user-guide.zh-CN.md)。

## 开始使用

1. 登录账号并打开已同步的工作区。
2. 从左侧 `AI Chat` 进入对话。
3. 使用输入区旁的 `+` 选择文档、标签、集合，或上传文件。
4. 在 `Workspace settings > AI context` 管理 Rule、Automatic Memory 和
   Context Project。
5. 从左侧栏 `Others > Help & guide` 打开应用内帮助页面。

> [!IMPORTANT]
> 对话读取文档后会保留快照。源文档被修改时，当前对话不会自动读取新版。
> 文档保存后，当前对话会在输入框上方显示可关闭的更新提示。请点击提示中
> 的 `New Chat` 新建对话，并重新选择或引用更新后的文档。关闭提示只对当前
> 保存版本生效；文档再次保存后会重新提示。切换到另一个旧对话不能刷新旧
> 快照。

## 十条实用提示

1. 一个对话只处理一个持续主题，目标改变时新建对话。
2. 修改文档后，需要最新内容就使用 `New Chat`，重新添加文档。
3. 问题中写清任务、资料范围、输出格式和不能猜测的内容。
4. 优先添加少量权威文档，不要一次选择大量无关资料。
5. Rule 使用简短、明确、可执行的句子。
6. Project Summary 记录稳定背景，不记录每天变化的流水账。
7. 定期检查 `Automatic` 列表，删除错误或过期记忆。
8. Automatic Memory 关闭后，已有记忆不会自动删除。
9. 不要在对话、文档、Rule 或 Memory 中输入密码、Token 和私钥。
10. 重要结论应回写到权威文档，不能只保留在聊天记录中。

## 推荐提问模板

```text
只根据我选择的文档完成以下任务：

任务：
资料范围：
输出格式：
必须保留：
禁止猜测：

无法从文档确认的内容请标记为“待确认”。
```

## 推荐 Rule 示例

```text
先给出结论，再给出依据和下一步。
```

```text
所有日期使用 YYYY-MM-DD 格式。
```

```text
无法从资料确认的信息标记为“待确认”，不要自行补全。
```

## Automatic Memory 示例

适合保存：

```text
记住：我更喜欢用表格比较多个方案。
```

```text
我们决定所有周报使用“完成、风险、下一步”结构。
```

不适合保存：

```text
帮我总结这份文档。
```

```text
部署代号是什么？
```

普通任务和问题不属于长期记忆。

## 文档更新检查单

文档内容变化后：

- 确认文档已经保存和同步；
- 等待当前对话输入框上方出现文档更新提示；
- 可以关闭当前版本的提示，文档再次保存后提示会重新出现；
- 停止继续使用原有对话；
- 点击提示中的 `New Chat`；
- 重新选择或引用更新后的文档；
- 要求 AI 只根据最新文档回答。

## 常见问题速查

| 现象                        | 处理方式                                |
| --------------------------- | --------------------------------------- |
| Automatic Memory 开关不可用 | 登录账号并同步当前工作区                |
| 看不到 `AI context`         | 检查服务器是否启用 Copilot              |
| AI 仍引用文档旧内容         | 新建对话并重新选择文档                  |
| 没有自动保存某句话          | 用“记住”或“我们决定”明确表达长期信息    |
| 关闭自动记忆后旧内容仍在    | 在 Memory 列表中停用或删除              |
| 普通成员无法创建项目        | 由工作区 Owner/Admin 创建               |
| 项目无法删除                | 先归档，并清理引用它的个人项目 Memory   |
| 搜索不到文档                | 检查权限、Embedding、索引进度和忽略列表 |
| 修改 Rule 后效果不明确      | 保存并启用后，在 `New Chat` 中验证      |
